# 小红书研究台：柔和磨砂玻璃界面

本 skill 只约束本项目视觉与交互呈现，不改变研究、采集或写作的业务范围。技术栈沿用 React + TypeScript + Ant Design + FastAPI + AgentScope。

## 设计依据

用户参考图为项目根目录 `1.jpg`；有图片查看工具时先查看它。详细分析及颜色角色见 [视觉规范](references/visual-spec.md)。实现时可取用 [CSS tokens](assets/soft-glass.css)，在项目样式入口导入，并按组件范围使用，不直接给所有元素附加玻璃效果。

参考图优先于早期 `research-dashboard-v1.png` 的配色。早期概念稿只继续作为信息布局参考。图片中的英文文案、组件拼贴和水印不属于产品内容。

## 必须保留的视觉特征

- 大面积暖奶油白，薄荷绿作为主要装饰与选中背景，少量淡桃粉作为局部光晕。深灰绿色正文，深青绿色主按钮。
- 外层面板使用半透明暖白、细亮边、低饱和阴影和较大圆角；光晕置于面板背景，内容层保持清晰。
- 胶囊分段控件、圆润按钮、充足留白、克制的线性图标。阴影柔和地向右下延伸，左上边缘较亮。
- 正文和数据区保持稳定实底或接近实底，不让彩色渐变穿过文字和表格行。

参考图是一张材质展示，不能据此认定具体字体、色值、尺寸或交互行为。规范中的数值是用于落地的近似设计选择。

## 落地方式

1. 先确定页面主任务和现有组件，读取视觉规范；保留研究任务、样本与分析、选题与草稿、设置四页结构。
2. 将颜色、圆角、字体映射到当前安装版本支持的 Ant Design 主题配置；材质效果用限定类名和伪元素实现。优先复用库的组件语义，不用装饰 div 替代按钮、表单和开关。
3. 每屏只突出一个主要操作。主按钮用实色深青绿加白字；薄荷色适用于选中底色，淡桃粉不代表错误或警告。
4. 玻璃材质用于导航容器、摘要卡片和选题卡。表格、编辑器、对话框正文优先清晰；弹层提高不透明度，避免和底层文字叠加。
5. 定义默认、悬停、按下、键盘焦点、选中、禁用、加载和失败状态。焦点环明确可见；选中状态同时使用文字、图标或边界变化，不只靠很淡的颜色。
6. 实现后用真实中文长度、长标题、空数据、错误状态及窄屏检查。验证文字对比度、键盘操作和横向溢出；有浏览器工具时查看实际页面，未运行则明确说明。

## 约束与取舍

- 不使用大面积高饱和红色、黑色背景、霓虹光晕、厚重阴影或每个表格单元格各自凸起的效果。
- 不照搬参考图中低对比白色按钮文案；正常文字目标对比度至少 4.5:1，控件边界和焦点指示目标至少 3:1，在实际叠加背景上验证。
- 不给整个应用或每一行表格叠加 backdrop-filter；只在少数容器启用。无模糊支持时使用暖白实底降级。
- 图表的系列使用深浅有区别的青绿、灰蓝及必要的暖色，配标签、线型或图例；不把装饰薄荷和桃粉直接当作可辨识的数据调色板。
- 不为实现此风格引入图片生成或额外 UI 框架；优先 CSS 与 Ant Design。用户明确要求新图像时另行处理。
- 后续用户指定的视觉调整优先于此规范。
