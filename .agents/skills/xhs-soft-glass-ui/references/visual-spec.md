# 参考图分析与前端视觉规范

## 观察与解释

`1.jpg` 展示透明圆角卡片、分段选择、滑块和开关。画布为暖白，面板内部有朦胧的薄荷绿与桃粉；边缘呈双层细亮线，白色旋钮有柔和投影。文字偏深灰、字重较轻，外围留白充足。

可将其概括为“低饱和磨砂玻璃 + 柔和新拟态”。这是一种视觉描述，不代表原作者的正式命名。其通透感主要来自背景色透出、亮边、内外阴影及渐变，而不只是 blur。原图未提供字体和设计源文件，下面的颜色、尺寸是视觉估计后为网页可读性调整的建议值，并非像素取样结果。

## 配色角色

| 角色 | 建议值 | 使用方式 |
| --- | --- | --- |
| 页面底色 | `#F7F4EE` | 暖奶油白，大面积使用 |
| 实底面板 | `#FCFAF6` | 表格、编辑区、弹层与降级背景 |
| 玻璃面板 | `rgba(255,255,255,.66)` | 外层容器，随真实背景调整 |
| 薄荷装饰 | `#C9E2D9` | 局部渐变、选中背景 |
| 青绿装饰 | `#8DBEB3` | 分段高光、非文字装饰 |
| 桃粉装饰 | `#EFCFC7` | 少量卡片光晕，不表示风险 |
| 主操作 | `#28665D` | 按钮、链接、焦点环 |
| 主操作悬停 | `#20564E` | 明确但温和的交互反馈 |
| 主要文字 | `#293631` | 标题、正文和重要数据 |
| 次要文字 | `#59665F` | 辅助说明，避免过淡 |
| 装饰边线 | `#D9DFD6` | 卡片边界；不能代替可辨识控件边框 |
| 控件边线 | `#7B8981` | 输入框或需要辨识的边界 |

暖白与中性色约占 80%，薄荷相关约 15%，桃粉约 5%，仅作为视觉分配起点。错误、警告、成功等语义色独立定义，搭配文字和图标；不强制变成低对比粉彩。

## 材质、排版与尺寸

- 页面内边距桌面 24—32px，窄屏 16px；间距采用 4、8、12、16、24、32px。
- 主要卡片圆角 24px，次级容器 16px，普通输入和按钮 12px；分段选择和标签可用胶囊圆角。数据表本身不需要每行圆角。
- 卡片边缘以 1px 亮线、轻微内阴影和向右下的柔和外阴影体现厚度；阴影不得遮盖邻近区域。
- 中文字体使用系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，不声称与原图字体相同。
- 页面标题 28—32px / 600，区块标题 18—20px / 600，正文 14—16px / 400，辅助说明 12—13px / 400，正文行高 1.6。避免为模仿原图使用过细中文字重。
- 常用控件约 40px 高；统计数字 28—32px，采用等宽数字特性以减少刷新时跳动。
- 状态过渡约 160—200ms，以边框、背景和阴影变化为主；尊重减少动画偏好，不使用持续漂浮的光斑。

## 四页映射

| 页面 | 如何应用参考风格 | 需要克制的区域 |
| --- | --- | --- |
| 研究任务 | 外层磨砂配置卡、薄荷分段选择、深青绿启动按钮 | 进度和失败原因必须清楚，不能只有装饰光点 |
| 样本与分析 | 薄荷摘要卡、柔和图表容器、暖白导航 | 样本表用稳定实底，原始指标和证据链接保持可读 |
| 选题与草稿 | 少量薄荷与桃粉选题卡、圆润标签 | 长文编辑区用接近白色的实底，不叠彩色渐变 |
| 设置 | 有间隔的暖白设置分组、标准语义开关 | 连接失败与预算超限使用明确状态文字 |

桌面保留左侧导航与主工作区。窄屏将导航折叠，筛选换行、卡片单列；表格在自身容器横向滚动。不要照搬原图的固定拼贴坐标。

## Ant Design 实现边界

使用项目安装版本的主题接口映射主色、文字色、布局底色、容器底色、字体和圆角。全局主题负责一致性；玻璃外壳、装饰渐变和特殊卡片由项目 CSS 控制。不要依赖未经核对的内部 DOM 选择器或大范围 `!important` 覆盖。

实现验收：正文在渐变最亮和最暗位置均可读；键盘焦点不被容器裁切；禁用与选中能区分；模糊关闭仍可用；表格与编辑区没有背景串字；内容没有因仿制材质而丢失来源、样本量和错误提示。
