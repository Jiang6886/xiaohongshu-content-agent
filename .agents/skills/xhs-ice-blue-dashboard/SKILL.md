# 冰蓝科技看板

本 skill 是项目第二套可选视觉方案，采用 React + TypeScript + Ant Design。它不自动替代第一套 `xhs-soft-glass-ui`，也不改变 FastAPI、AgentScope 与业务模块。用户选择第二套、冰蓝科技风或 `2.jpg` 风格时应用。

## 参考与资源

- 原图位于项目根目录 `2.jpg`，可查看图片时先观察原图。
- 设计与页面映射见 [视觉规范](references/visual-spec.md)。
- [CSS tokens](assets/ice-blue.css) 提供颜色和容器起点；按页面作用域使用，勿直接影响第一套主题。

原图含两个设计案例，不是同一个产品的两页。上方宣传标题、签名、水印、英文姓名和建筑内容不属于本项目。颜色和尺寸是视觉估计后的网页落地建议，不声称还原原始设计 token。

## 选择合适的表现强度

- **常规工作台（本风格默认）：** 参考上半部分的冰蓝背景、白蓝卡片、圆角和柔和阴影。用清楚的导航、表格、筛选与编辑界面承载研究工作。
- **概览大屏（用户要求时）：** 可借鉴下半部分的蓝色细边、分区标题、较大的中心可视化和侧栏指标。保持内容可读，不自动增加 Three.js、3D 场景或复杂动效。
- 不混用厚重工业装饰边框和每张卡片都凸起的新拟态；根据页面目的选择一种主要表达。

## 视觉原则

1. 使用浅冰蓝画布、接近白色的内容面板、深蓝灰正文。电光蓝用于主操作、选中和主要数据系列；青色用于少量辅助线或标记。
2. 光感来自浅背景、亮边、柔和蓝灰阴影和少量冷色渐变，而不是大面积模糊与强烈霓虹。表格与长文区使用稳定实底。
3. 数据层级优先：页面结论和关键数值最大，其次图表及图例，最后解释与采样说明。图片顶部的巨大宣传标题不能当作应用标题比例。
4. 图表需要实际数据意义；圆环只用于有明确分母的进度或比例，不用仪表盘装饰一个普通计数。保留样本范围、单位、来源和空数据状态。
5. 网格底纹、发光连线、切角边框只可用于少量概览区域，不穿过表格正文。3D 仅在确有空间或拓扑含义且用户需要时考虑，不把房屋模型替换成无意义的立体装饰。

## React / Ant Design 落地

- 先读取视觉规范，再把主色、文字、面板背景、字体和圆角映射到当前安装版本支持的主题配置；以页面作用域类和 CSS 实现特殊材质。
- 四个页面仍为研究任务、样本与分析、选题与草稿、设置。常规页面维持左侧导航；分析页可采用主要图表区域加右侧洞察栏。
- 复用 Ant Design 的表格、表单、分段选择和抽屉，保留键盘语义与默认行为。不要为了仿图用静态绘图代替可操作控件。
- 定义悬停、按下、焦点、选中、禁用、加载、失败及空数据状态。蓝色主按钮配白字；浅蓝选中底配深色文字。
- 普通文字目标对比度至少 4.5:1；焦点和需要识别的控件边界至少 3:1，在最终背景上检查。低饱和装饰蓝不能直接承担正文。
- 图表使用可区分的系列颜色及标签、线型等辅助表达；不只靠蓝色深浅区分所有系列。状态颜色另行定义，不能所有错误都画成蓝色。
- 桌面可多列，窄屏顺序堆叠；表格在自身区域滚动，不整体缩小大屏截图以适配手机。
- 检查真实中文长标题、稀疏数据、图例、错误与窄屏；有浏览器工具时检查实际渲染，未运行时说明。避免持续旋转、流光和无意义数字跳动，尊重减少动画偏好。

## 与第一套风格的边界

本套使用冷色光感和数据层级，不引入第一套的大面积奶油白、薄荷与桃粉。只有用户要求混合或切换主题时才整合；主题切换不在本次制作 skill 的实现范围内。
