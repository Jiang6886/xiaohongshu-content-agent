# 2.jpg 分析与视觉规范

## 原图中的两种表达

| 观察 | 上半部分 | 下半部分 |
| --- | --- | --- |
| 内容结构 | 左侧建筑空间，右侧趋势、温度和设备卡片 | 中心立体节点，右侧比例指标，底部列表 |
| 容器 | 圆角、浅白蓝、柔和阴影 | 分区细线、科技边框、偏灰蓝半透明面板 |
| 强调色 | 蓝、青，局部绿与橙 | 蓝白发光连线，少量黄色 |
| 视觉重心 | 空间场景与设备控制 | 节点关系与监测指标 |
| 本项目可借鉴 | 浅色卡片工作台、清晰模块分组 | 概览的信息分区与主要可视化布局 |

两个案例共享冰蓝与雾灰画布、蓝色高光、细线和层次阴影。下方更接近工业监控大屏，上方更接近柔和的数字孪生控制界面。原图的具体字体、原始颜色和动效无法仅凭截图确认。

## 建议色板

以下为视觉近似及可读性调整值，未进行像素取样。

| 角色 | 建议值 | 用法 |
| --- | --- | --- |
| 页面背景 | `#EDF3F8` | 冷白与冰蓝之间的大底 |
| 外层背景 | `#E2EBF3` | 布局分区、次级区域 |
| 卡片背景 | `#F7FAFE` | 清晰内容面板 |
| 内容实底 | `#FFFFFF` | 编辑器、密集表格、弹层 |
| 蓝灰边线 | `#CDDCEA` | 非交互分隔与卡片边界 |
| 主操作蓝 | `#2463C5` | 按钮、链接、焦点 |
| 高光蓝 | `#3688FF` | 装饰高光与主要数据线，不直接配小号白字 |
| 辅助青 | `#78D4EA` | 少量节点、辅助背景 |
| 主文字 | `#25364A` | 标题、正文、指标 |
| 次文字 | `#586C82` | 说明、图例 |
| 选中背景 | `#E0EDFF` | 分段选中、选中行，搭配深蓝字 |
| 控件边线 | `#71849A` | 需明确识别的输入边界 |

暖色只在不同数据系列或状态确有需要时加入。原图宣传文字中的紫色不是主体应用配色，无需为此新增紫色主按钮。

## 排版与材质

- 页面标题 28—32px / 600，区块标题 16—20px / 600，正文和数据表 14—16px，辅助信息至少约 12—13px；不要照搬截图缩小后的细小字号。
- 字体使用系统中文无衬线栈；数字启用 `font-variant-numeric: tabular-nums`。不为了“科技感”使用难读的装饰字体展示中文和长文本。
- 普通卡片圆角 16—20px，输入和按钮约 10px；选中分段可用胶囊。工业概览的分区可以更方正，但不全站使用切角装饰。
- 间距采用 4、8、12、16、24、32px；桌面主区内边距 24—32px，窄屏 16px。
- 面板使用 1px 亮边、微弱顶部高光和蓝灰投影。阴影服务于层次，不让每个数字、图标和单元格都悬浮。
- 装饰网格低对比，仅用于非文字密集区域。编辑区不铺网格，表格行不叠渐变。

## 项目页面应用

| 页面 | 适用设计 |
| --- | --- |
| 研究任务 | 蓝色主按钮、白蓝配置卡、阶段步骤、可展开错误详情 |
| 样本与分析 | 顶部指标、中央分布与对比图、右侧洞察和样本依据、下方可筛选样本表 |
| 选题与草稿 | 低装饰选题卡、深蓝标题、稳定白色编辑区与证据抽屉 |
| 设置 | 清楚的分组表单，连接状态配文字和图标，避免监控大屏式堆砌 |

只有用户明确需要独立概览大屏时才扩展布局。没有关系数据时不做主题关系网络；没有曝光或点击时不做点击率仪表；没有重复快照时不做增长趋势。视觉不能把示例数据变成真实研究结论。

## 与 1.jpg 的差别

第一套偏暖、柔软、磨砂玻璃和个人创作空间；本套偏冷、清晰、科技控制台和数据概览。两套都能适配四页业务，但不要在同一页面随意混合两套主色、阴影和组件圆角。
