## 已实现

- FastAPI 业务接口：22 个路径、26 个操作，运行代码导出的 OpenAPI。
- SQLite 持久化：研究、任务、批次笔记、指标快照、选题、草稿及完整历史、设置与幂等记录。
- 独立单 worker：队列、阶段进度、协作取消、显式重试、重启恢复和独立心跳。
- 只读 MCP 连接器：登录检查、关键词搜索、详情和有限评论、指标解析、来源记录、失败状态。
- AgentScope 2.0.8 模型适配：主题分类、选题、草稿；预算预留、超时、结构和证据校验。
- JSON 手工导入：去重、未知指标处理、报告统计、批次内排除和导出。
- 前端默认连接真实 HTTP；独立保留 demo 模式，不自动导入旧演示数据。
- 前端新增连接状态、后台任务、重试、导入、历史草稿查看、模型未配置反馈。

## 现阶段边界

- 单用户本地应用，没有公网认证和多用户隔离。
- 取消按步骤边界执行，不能保证马上中断外部请求。
- 采集恢复会重新搜索，不保证平台搜索结果与中断前完全一致。
- token 预算使用保守字节估算，不是指定模型的精确分词计数；实际用量单独保存。
- 按预算截取素材，报告明确记录模型实际分析的 ID；其余内容不声称已分类。
- 前端目前读取所有分页后在页面筛选；服务端已支持分页，大规模数据需要优化前端加载策略。
- P1 定时趋势跟踪、个人发布效果复盘、OCR/视频理解未实现。
- 数据库仅实现初始 schema v1，后续结构变化需版本化迁移。
- 前端仍有单个 JS chunk 大小提醒，正式远程部署前可按路由拆包。
