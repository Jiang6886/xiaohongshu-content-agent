# 前端模拟版验收记录

日期：2026-09-25。风格依据：第一套 xhs-soft-glass-ui / 1.jpg。

## 已完成

- React + TypeScript + Ant Design + Vite 前端，四页路由与响应式布局。
- 研究创建、模拟进度与取消；样本筛选、排序、证据详情、排除与恢复。
- 话题分布、简单标题特征观察、选题收藏与写作材料录入。
- 模板草稿生成、Markdown 编辑预览、版本保存及文件下载。
- 作者和预算设置、模拟连接状态、演示数据重置。
- API 中文说明与 OpenAPI 3.1 JSON：19 个路径、23 个操作。

## 验证结果

- `npm run build`：TypeScript 检查和生产构建通过。
- Playwright 四个用例均已通过（分批执行）：
  - 筛选、证据查看、排除样本、生成草稿、保存、预览、验证下载文件名和正文标题、刷新恢复。
  - 新研究创建、取消、正常完成与结果跳转。
  - 390px 窄屏无页面级横向溢出；设置保存后刷新仍可读取。
  - 采样上限为 1 时选题不含悬空证据；过期草稿版本保存被拒绝。
- 实际检查了桌面和手机截图，截图位于 docs/design。
- OpenAPI JSON 可解析、内部 schema 引用存在、operationId 唯一；未宣称进行完整 OpenAPI 规范校验。
- 文档本地链接检查通过。

测试过程中修复了生成结束前保存按钮短暂可点击的问题、标题修改未同步导出正文的问题，以及低采样上限导致证据引用超出已有样本的问题。

## 当前边界

- 所有数据均为虚构。MCP、模型与 FastAPI 未连接，页面没有真实登录或发布功能。
- 新任务最多复制 12 条固定素材；进度由演示数据层按时间计算，不是后台 worker。
- 数据保存在当前浏览器，模拟草稿只保存最新内容与版本号；后端应保存完整历史。
- 单次排除会即时更新统计，固定演示选题不会重新推理；实际后端需标记语义分析过期。
- 构建存在单个 JS chunk 体积提醒（约 1.22 MB 未压缩，约 398 KB gzip）；本地演示可用，正式上线前按路由拆包与按需加载。
- 浏览器内的未保存编辑不是完整自动保存功能，建议离开编辑器前保存或导出。
