# 领域爆款研究

目标是从领域内高互动候选中发现可复用的内容特征，再用自己账号发布的真实数据验证，而不是仅按最新搜索结果概括话题。

## 当前已实现

新建研究默认选择「高互动筛选」。每个关键词分别搜索最多点赞、最多收藏、最多评论，不因首个关键词达到样本上限就提前停止搜索。支持图文与视频、仅图文、仅视频。

各关键词和排序轮流提供详情候选，跨组去重。详情核验上限为 `min(max(30, 3 × 最终样本上限), 100, 剩余工具调用预算)`。这不是全站爬取，也不保证拿到领域内所有爆文。

发布时间必须已知且在研究范围内，类型须匹配。默认门槛为点赞 1000、收藏 300、评论 100，满足任一开启的门槛即达标。用户可调整；0 关闭对应门槛，全部关闭则至少有一项互动大于 0。未知指标不能通过对应门槛。门槛只是初始筛选条件，不是通用爆款标准。

最终入选可按点赞、收藏、评论或均衡指标排序。均衡分数为三项 `log(1 + 互动数)` 之和，未知项仅在排序计算中贡献 0，但原始数据仍标为未知。分数用于已核验候选之间比较，不是点击率、账号归一化表现或成功概率。

达标不足不使用低互动样本凑数。研究保存搜索组数、候选数量、详情核验数、达标数和入选数，在分析页「筛选依据」查看。重试保留已入选材料并补足剩余名额；要重新比较完整候选池，应新建研究。旧研究和旧接口默认策略保留「最新内容探索」，不会被自动改写为爆款研究。

## 共性分析

「共性爆点」展示最多五项：

- **观察**：标题、正文和部分评论中实际出现的共同特征。
- **假设**：这些特征可能满足什么需求或情绪，不把它写成已证明的传播因果。
- **证据**：每条共性至少引用两个不同的输入样本，可以打开详情追溯。
- **实验**：如何用自己的经验形成原创内容，并与自己账号的普通内容对照验证。

输入保留内容类型、发布时间、互动数、作者 ID、最多 1200 字正文及最多 6 条已采集评论；正文截断会标记。总预算可能进一步减少输入样本，实际分析覆盖数与入选数可能不同。没有足够证据时允许不生成共性。评论是有限样本，不能代表所有受众。

## 尚未具备的能力

| 数据或分析 | 当前状态 |
| --- | --- |
| 点赞、收藏、评论数 | MCP 返回后解析，可能是近似数或未知 |
| 标题、正文、部分评论、笔记类型 | 可用于分析 |
| 点击、曝光、完播、单篇涨粉 | 当前适配器没有这些数据，不用互动数代替 |
| 封面构图、图片文字、视频前几秒、剪辑节奏 | 未做图片识别、视频转写或帧分析 |
| 作者粉丝基数与账号日常表现校正 | 未实现，不能称为「小号爆款」识别 |
| 普通内容对照组与发布后复盘 | 尚需扩展，当前实验建议不等于已验证结论 |

只观察高互动内容存在幸存者偏差。账号体量、发布时间、流量来源及其他因素也可能影响互动。后续应加入同领域、相近发布时间和账号规模的普通内容对照，以及自己账号的授权导出数据，逐步验证假设。

MCP 搜索参数依据：[所部署版本的官方搜索实现](https://github.com/xpzouying/xiaohongshu-mcp/blob/v2.5.5/xiaohongshu/search.go)。本次实现通过模拟 MCP 和隔离数据库验证；开发时本地 MCP 未启动，尚未完成新策略的真实平台采集验收。
